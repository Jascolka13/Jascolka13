# Hello World!

## About Me

I'm Henrique Viana, a BIM analyst, mechanical technician, and systems engineering student, passionate about technology, automation, and software development.
My career started in HVAC design, but over time I became increasingly interested in process optimization, BIM workflows, and software development. Today, I work on creating tools and automations that improve engineering workflows through Revit API, Dynamo, Python, and C#.
I enjoy solving complex problems, developing efficient solutions, and exploring how software can transform engineering processes.

## Areas of Interest

- Process Optimization
- Software Engineering

- Data Analysis & Automation
